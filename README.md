# martinnolan-dev

My personal site: [martinnolan-dev.netlify.app](https://martinnolan-dev.netlify.app).

One static page about how I build software. Next.js (App Router, static export), TypeScript and plain CSS, deployed on Netlify. No tracking, cookies or third-party requests.

## Run it

```bash
nvm use
npm ci
npm run dev
```

Node 22 is selected by `.nvmrc` and used by Netlify. `npm ci` installs the exact
dependencies in the lockfile. `.editorconfig` and Prettier keep editor settings consistent.

## Check it

```bash
npm run check
```

Formatting, lint (with accessibility rules), types and a production build. Netlify
runs the same command before deploying.

`npm run typecheck` generates Next.js route types before checking TypeScript, so
it works without first starting the development server or building the site.

TypeScript 7 runs the compiler (`tsc`). The `typescript` dependency uses the
official TypeScript 6 compatibility package because ESLint still needs the
JavaScript compiler API. ESLint stays on version 9 while the accessibility
plugin does not support version 10.

## Generated files

- `out/` is the deployable static site. It is ignored by Git and safe to delete
  locally; `npm run build` recreates it. Netlify publishes this directory.
- `.next/` holds generated types and build/development caches. It is safe to
  delete when no development server or build is running.
- `next-env.d.ts` is generated by Next.js. Keep it ignored and do not edit it.
  `npm run typecheck`, `npm run dev` and `npm run build` recreate it.
- `tsconfig.tsbuildinfo` is a disposable TypeScript cache.

This is a static export, so `next start` is not the production server. Serve the
contents of `out/` with a static host. Fonts are fetched at build time and then
self-hosted; a clean build may need network access for those downloads.

## Where things are

```text
src/
  app/          layout, page, 404 and styles
  components/   figure, section heading, intro, highlighter and SVG inliner
  content/      all copy
  figures/      hand-made SVG drawings
public/         favicon, link preview image, robots and sitemap
AGENTS.md       rules for anyone (or any agent) changing the site
DESIGN.md       type, colour and layout tokens
```
